
🌍 Geo Red Sea - Professional Surveying Solutions
Geo Red Sea is a high-end digital platform for a specialized land surveying company. This project showcases precision engineering services, a dynamic project portfolio, and a recruitment system, all wrapped in a modern, high-performance user interface.

🚀 Key Features
Multi-Language Support (i18n): Full support for Arabic (RTL) and English (LTR) with a seamless language switcher in the header.

Dynamic Testimonials: An interactive feedback section powered by Swiper.js and GSAP, featuring unique layouts like speech bubbles and "paperclip" image styling.

Recruitment System: A dedicated Careers section with a functional application form for specialized roles (GIS, Land Surveyors, etc.).

Modern UI/UX: Built with Tailwind CSS for a clean, minimalist, and "Navy-themed" aesthetic.

Smooth Animations: Advanced scroll-triggered animations using GSAP (ScrollTrigger) and Framer Motion.

Fully Responsive: Optimized for all devices, with a custom mobile navigation that includes quick-access language switching.

🛠️ Tech Stack
Frontend: React.js (Functional Components & Hooks)

Styling: Tailwind CSS

Animations: GSAP & Framer Motion

Slider: Swiper.js

Internationalization: i18next

Icons: Lucide React

Routing: React Router Dom

📦 Installation & Setup
Clone the repository:

Bash
git clone https://github.com/your-username/geo-red-sea.git
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Build for production:

Bash
npm run build
📁 Project Structure Highlights
src/components/Testimonials.tsx: Custom Swiper implementation with GSAP logic for animated waves and cards.

src/components/Header.tsx: Responsive navigation bar with integrated LangSwitcher.

src/i18n/: Contains ar.json and en.json for full content translation.

src/components/LangSwitcher.tsx: Logic for toggling between Arabic and English.
